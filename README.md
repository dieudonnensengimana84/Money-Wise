# MoneyWise Pro

A responsive, browser-based financial education app built with plain HTML, CSS, and JavaScript. It uses the dark navy and warm-gold visual language of the supplied Nedo Light login UI and continues that styling throughout the learning dashboard.

## Features
- Demo sign-in and account creation stored locally in the browser
- Responsive dashboard and dark/light appearance toggle
- Four guided financial learning paths with lesson completion tracking
- Monthly budget simulator with live remaining-income calculation
- Savings goals and sample contribution tracking
- Decision lab with explanations and progress tracking
- Progress dashboard and reset-demo-data action
- Local persistence via `localStorage`; no backend or bank connection required

## Run
1. Extract the ZIP.
2. Open `index.html` in a modern browser, or serve this folder with any static web server.
3. Create a demo account with an email and password, or enter any email and password to use demo sign-in.

## Important notes
- This is a front-end educational prototype, not a production banking or financial-management service.
- Demo credentials are stored locally and are not securely hashed. Do not use a real password.
- Google/GitHub buttons explain that OAuth is not configured; real social login requires provider credentials and a backend.
- Data stays in the current browser profile and can be cleared by resetting demo data or clearing browser storage.
- Currency values are illustrative Rwandan francs (RWF). Lessons are educational, not personalized financial advice.
